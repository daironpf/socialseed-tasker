# Issue #243: Fix docker-compose frontend build failure

## Description
The docker-compose.yml generated by tasker init fails to build because package.json is missing in the frontend build context.

## Expected Behavior
`docker-compose build tasker-board` succeeds.

## Actual Behavior
Error: "/package.json": not found

## Steps to Reproduce
1. Run: `tasker init .`
2. Run: `docker-compose build tasker-board`
3. Observe: Error about missing package.json

## Status: COMPLETED

## Priority: MEDIUM

## Component
DOCKER

## Suggested Fix
- Option 1: Copy full frontend from main project to tasker/frontend/
- Option 2: Modify docker-compose to use Dockerfile that doesn't require npm
- Option 3: Use docker-compose-minimal.yml which only starts Neo4j

## Impact
Cannot do full docker build for evaluation.
