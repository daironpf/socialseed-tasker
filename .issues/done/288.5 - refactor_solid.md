# Refactorizar ficheros grandes para aplicar principios SOLID

El proyecto contiene ficheros extremadamente grandes (ej. `routes.py` con >5600 líneas, `commands.py` con >3000 líneas y `repositories.py` con >1400 líneas). Esto viola el Principio de Responsabilidad Única (SRP) de SOLID, haciendo el código difícil de mantener, propenso a conflictos de merge y complicado de navegar.
El objetivo es dividir estos "God Modules" en módulos más pequeños y cohesivos, manteniendo la arquitectura hexagonal y aplicando restricciones claras de dependencias.

## User Review Required

> [!WARNING]
> Este refactor implicará mover gran cantidad de código. Aunque la lógica de negocio no cambiará, la estructura de carpetas de los entrypoints (`web_api` y `terminal_cli`) y `storage` se verá modificada. Por favor, revisa si la nueva estructura propuesta se alinea con tu visión.
